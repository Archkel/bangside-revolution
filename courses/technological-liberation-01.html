TECHNOLOGICAL LIBERATION / LESSON 01

BUILD YOUR FIRST
WEBPAGE.

Learn the foundation of the web by creating a simple personal portfolio page. You will work with HTML for structure and CSS for appearance, then save a project you can improve and show to others.

What you'll complete

  • Understand the difference between HTML and CSS.
  • Create a personal portfolio page with a heading, introduction, and skills list.
  • Download a working starter project to edit on your device.
  • Identify the next steps toward publishing a portfolio online.

Time: 25–40 minutes. Deliverable: a starter portfolio webpage.

Part 1 — Understand the building blocks

HTML describes the content and structure: headings, paragraphs, links, and lists. CSS controls how that content looks: colors, spacing, typography, and layout. A browser reads both to display the page.

You do not need to memorize everything. Learn to read the code, change a small piece, and observe the result.

Part 2 — Your first HTML example

This is a complete, minimal webpage. The text between tags becomes visible content in the browser.

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My First Page</title>
</head>
<body>
  <h1>My Name and My Work</h1>
  <p>I am building useful skills and projects.</p>
  <h2>Skills I Am Developing</h2>
  <ul>
    <li>Web development</li>
    <li>Problem solving</li>
  </ul>
</body>
</html>

Try changing the heading and list items when you open the downloaded project in a text editor. Keep the opening and closing tags paired.

Part 3 — Add your own project details

Use the generator below to create a starter portfolio file. Use a public display name or project name if you prefer not to share personal information. Do not include your home address, passwords, or private account details.

The generator creates an HTML file in your browser. Your entries are not sent to this website or saved to a user account.

Part 4 — Test your work

  1. Download your HTML file.
  2. Open it with a browser or compatible HTML editor.
  3. Check that your heading, introduction, skills, and project all appear.
  4. Change one sentence in the code and reopen the file to confirm your edit.
  5. Keep a copy of the original and your edited version.

A file on your device is a local project, not yet a public website. Publishing requires a hosting service or web server and a review of what information you make public.

Completion standard

You have completed this lesson when you can explain what HTML does, identify what CSS does, generate your page, open it successfully, and make one change yourself.

This lesson provides a beginner exercise, not a job credential or a promise of income. Build and test projects before offering paid services.

Welcome to Bangside Revolution. This lesson is called Build Your First Webpage.

Today, you will learn the foundations of web development by creating a simple personal portfolio. You do not need to be an expert programmer. You need a device, a text editor, a browser, and the willingness to experiment.

Let's start with two essential building blocks: HTML and CSS.

HTML stands for HyperText Markup Language. It defines the structure and content of a webpage. Headings, paragraphs, links, and lists are all examples of HTML content.

CSS stands for Cascading Style Sheets. CSS controls presentation: colors, spacing, fonts, borders, and page layout.

Think of HTML as the structure of a building and CSS as the design of its rooms. They work together, but they serve different purposes.

You do not have to memorize every tag or property. Learn to read the code, make one small change, and observe what happens.

Part one: understand the structure.

A basic HTML document begins with a declaration that tells the browser to use modern HTML. The HTML element contains the page. The head contains information about the document, including its title. The body contains the content people see.

Headings organize information. Paragraphs explain ideas. Unordered lists group related items. Opening and closing tags usually work together, so keep them paired.

Part two: create your first page.

Open a text editor and create a new file named index dot html. Add a heading introducing yourself or your project. Under it, write a short paragraph explaining what you are learning or building. Then add a list of three skills you are developing.

Save the file. Open it in a web browser. You should see your heading, introduction, and skills list.

If something does not appear correctly, do not panic. Check the spelling of your tags, make sure the closing tags are present, and confirm that you saved the file with the HTML extension.

Part three: make it your own.

Use the portfolio generator on the lesson page to create a starter file. Choose a public display name or a project name. Write a short tagline. Add skills you are genuinely developing, and describe a project you are working on.

Protect your privacy. Do not put your home address, passwords, private account details, or other sensitive information into a portfolio. Before publishing anything, review what visitors will be able to see.

Part four: test your work.

Download your generated HTML file and open it with a browser or compatible HTML editor. Confirm that the heading, introduction, skills, and project appear.

Now change one sentence in the code. Save the file and reopen it. Confirm that your change appears. Keep a copy of the original and your edited version so you can recover if something goes wrong.

Remember: a webpage saved on your device is a local project. It is not yet a public website. Publishing requires a hosting service or web server, and you should review your content before making it public.

Here is your completion challenge. Explain, in your own words, what HTML does and what CSS does. Generate your portfolio page. Open it successfully. Then make one change yourself and verify the result.

You have completed this lesson when you can perform those steps without simply copying instructions.

Technology becomes more useful when you can understand it, shape it, and use it to build something of your own. Start small, test your work, protect your information, and keep learning.

Thank you for learning with Bangside Revolution. Your next step is to keep improving your portfolio and explore how a local webpage can eventually become a published website.
